2. 世界觀與劇情

2.1 世界觀

里拉王國是音樂之國：清晨有鐘聲，傍晚的廣場上總有人唱歌。主題是變聲期的憤怒與羞恥——塔裡遇到的敵人其實都是主角自己：5F 鼓魔像是怒氣、10F 弦之魔女是別人的眼光、15F 回音之鏡是一直拿現在跟小時候比的那個他、塔頂的靜默指揮家是想把所有聲音關掉的那個他。

3. 核心玩法

3.1 移動與操作

操作行為（main.js）
點地圖格子BFS 找路：先只走空地，走不到才允許順路撿道具（findPath）；夾擊、共鳴的格子和回音地板都繞開，真的繞不開才走「付的生命最少、再來步數最少」的路（cheapest，3.1）。整條路線要付的生命先算好（routeToll）：付不起直接擋下來，付得起光標變粉紫色；畫一條淡白細線＋終點圓角光標（約 1.6 秒呼吸一次），勇者每 105ms 走一格，走過的線段消失。走到一半點別處就改走新路線；點自己停下；點牆、鐵門或走不到的格子閃紅色 ✕
點怪物／門一下就出發（2.0.9 起不需再點確認）。出發前先檢查：打不動（攻擊 ≤ 怪物防禦）、打不贏（損失 ≥ 目前生命）、沒鑰匙，直接擋下並提示原因，不會白走。走去開打時光標帶淡紅色
長按（420ms）怪物、道具、門、鐵門、樓梯、商人／祭壇、NPC 跳說明卡（怪物＝圖鑑那一列：能力與預估損失；門＝要哪把鑰匙與身上幾把；道具＝撿起來加多少）。手指移動超過 14px 取消長按；手機會震動 15ms。說明卡放在地圖外（直向在地圖上方，橫向在左欄功能鍵下方）
查看模式功能鍵列第一顆「查看」：開啟時按鈕變黃、地圖框淡黃，點一下只看說明不移動；再按一次、Esc、返回鍵或方向鍵離開
鍵盤方向鍵／WASD 走（按住每 125ms 連續走）；B 圖鑑、F 飛行、Shift+S 存讀、Esc 選單（查看模式中為離開查看）；Enter／空白鍵推進對話與過場
數值變動撿道具、買東西、升級、劇情給東西時，「+N」從那一格飛進資訊列對應的欄位（flyGains），顏色跟資訊列同一組：生命紅、攻擊橘、防禦藍、金幣黃，只在 style.css 的 --hp／--atk／--def／--gold 定義一次（3.0.3）；鑰匙飛的是鑰匙圖
功能鍵列查看／圖鑑／飛行／存讀／選單。圖鑑分「怪物｜收藏品」兩頁（3.2.0）：怪物頁不分樓層列出全部怪物，打倒過才顯示能力（沒打過的是剪影＋？？？；二階段指揮家打倒前不列，3.2.64 Ken 指定），沒打過的怪要看能力就長按牠；收藏品見 3.4；面板固定大小、分頁鈕釘在上面，切分頁只換內容不重開面板（3.2.1）
教學完整教學：標題畫面、選單 → 教學、或資訊列樓層下方的「？」（3.1.3），8 頁圖文（目標、移動、戰鬥、鑰匙與門、道具、金幣與經驗、怪物特技、小技巧），左右鍵或下方圓點翻頁；面板固定大小，內容在中間捲、翻頁列釘在底部，每頁「下一頁」都在同一位置（3.2.1）。示意圖由 tutScene 用地圖同款圖塊即時畫出，戰鬥頁的損失數字照 MT.calc 實算（假設生命 200／攻擊 10／防禦 10），改數值不用改圖；戰鬥頁的 ??? 畫紅色、「這場會損失的生命」畫重點色（i18n 裡用 **…** 標，tutFmt），《怪物圖鑑》那列拿到圖鑑才顯示（3.2.11）

3.2 戰鬥公式（MT.calc）

勇者先攻、雙方輪流，戰鬥結果在開打前就確定：

若怪物有 invincible → 打不動（damage = null）
heroHit = 勇者攻擊 − 怪物防禦               // ≤ 0 → 打不動
def     = 技能「鐵壁」? 勇者防禦 ＋ min(⌊勇者防禦 × (倍數 − 1)⌋, 上限) : 技能「連擊」? ⌊勇者防禦 × 0.93⌋ : 勇者防禦
raw     = magic  ? 怪物攻擊                   // 魔法：無視防禦
        : pierce ? max(0, 怪物攻擊 − ⌊def/2⌋) // 破甲：防禦只算一半
        :          max(0, 怪物攻擊 − def)
monHit  = raw
strikes = [heroHit] ＋ 技能「連擊」每回合額外的那幾下
drain   = 吸血 ? ⌊目前生命 × m.drain⌋ : 0      // 開打前先吸

沒有反彈：turns = ⌊(怪物生命 − 1) / Σstrikes⌋ + 1
          怪物出手 = turns − 1 (+1 先攻)
有反彈（技能「反彈」）：照回合模擬，怪物每出手一下就扣自己 ⌈raw × 反彈比例⌉
damage  = drain + 怪物出手 × (連擊 ? 2 : 1) × monHit
  • 能不能打：damage == null 或 damage ≥ 目前生命 時拒絕開打
  • 勝利：生命 −damage、金幣與經驗值增加、整塊（大型怪物）變空地，再檢查本層鐵門
  • 夾擊（MT.pincerAt）：走進兩隻夾擊怪（左右或上下）中間的格子，立刻失去目前生命的 1/3
  • 回音地板、共鳴（3.1）：見 3.13。兩者付了會倒下就不走（事件 tooHurt），跟打不贏的怪一樣擋下來
  • 大型怪物：size 2 或 3，地圖上 size×size 格都寫同一個代碼、共用一條血（MT.blockOrigin、MT.clearBlock）
  • 攻擊減少回合數、防禦減少每一下：兩者價值比 ≈（怪物每下傷害）÷（勇者每下傷害），所以高攻怪讓防禦值錢、高血高防怪讓攻擊值錢

6. 系統

6.1 存檔（sync.js、main.js）

  • 結構：一條清單 { v: 2, list: [...] }，存在 localStorage 的 mt.saves2。每格有 id、kind（auto／manual／best）、裝置 id 與名稱、時間、樓層、生命、data（MT.pack 後的狀態，地圖壓成字串）
  • 自動存檔：每台裝置各一格（id a:<裝置 id>），最多保留 20 台裝置。時機：換樓層、劇本播完、戰鬥後、買東西、飛行、回標題、切到背景／關分頁（visibilitychange、pagehide、App 的 appPause）。劇本播到一半不存，避免「旗標已設、道具未給」的狀態
  • 手動存檔：所有裝置共用，最多 99 格、新的在前，滿了再存擠掉最舊的；別台裝置存的只能讀不能覆蓋
  • 繼續遊戲：接所有裝置裡最新的自動存檔
  • 最佳紀錄：kind best，一台裝置一格，標題畫面顯示所有裝置裡最好的一次
  • 版本相容：MT.SAVE_V = 3，3.0.0 起 20 層、地圖全部重畫，2.x 存檔（v2）列出但讀不了；MT.migrate 補新欄位（3.1 起還會把沒去過的樓層換成新地圖，見 3.13）
  • 裝置 id 第一次使用時隨機產生，存在 mt.device

6.2 雲端同步

  • 存在使用者自己的私有 GitHub repo，預設 agan0617/CloudSave，檔案 saves/magictower/saves.json（1.5.0 起）。舊位置 saves/magictower.json（1.4.2～1.4.4）與根目錄 saves.json（更早）會在拉取時併入並刪除
  • 每台裝置貼一次 GitHub fine-grained token（Repository access 只選該 repo、Contents: Read and write），只存在該裝置 localStorage（mt.gh）；瀏覽器直接打 GitHub Contents API，無中間伺服器。同一支 token 可與 K書吧等其他 App 共用
  • 合併規則：兩邊格子聯集，同 id 取時間較新者；每台裝置只寫自己的格子，所以不互相覆蓋
  • 推送：存檔後 2.5 秒內合併推送；遇 409／422 衝突重抓重試最多 4 次；切背景時以 keepalive 推送
  • 拉取：標題畫面、回到前景時拉取；別台裝置有較新的自動存檔會詢問要不要讀取
  • 入口：存檔頁最下方「● 雲端同步」按鈕、標題畫面連結。狀態：未連線／同步中／已同步／離線／同步失敗（401、403、404 有專屬說明）

6.3 多語系（i18n.js）

  • 中文（繁）、English、日本語三套，介面字串與劇情（story）分開；MT.t 取介面字、MT.story 取劇情，{n} 形式填值
  • 預設依 navigator.language：ja→日文、zh→中文、其他→英文；設定頁可切換，記在 mt.lang

6.4 音樂音效設定

  • 設定頁有音樂、音效兩條音量滑桿（0～1，預設各 1（3.2.22 起，原 0.8）；只影響還沒存過設定的玩家；標題曲另外整首壓到一半 SONGS.title.gain），記在 mt.settings。切到背景時暫停 AudioContext

6.5 離線快取（sw.js）

  • 僅在 https 下註冊 service worker；快取名 mt-3.2.73，安裝時以 cache: 'reload' 預先快取全部檔案（繞過 GitHub Pages 的 10 分鐘 HTTP 快取，避免新頁配舊 js）

  • Android App 外殼也是開線上網址，一樣靠這個離線

8.2 資料流

輸入（點擊／長按／鍵盤／App 返回鍵）
  → main.js：tapTile → findPath（BFS，繞不開才 cheapest）→ routeToll → walkRoute → stepOnce(dir)
    → core.js：MT.step(st, dir) 改狀態，回傳事件
        move／bump／secret／break／noChisel／fight／cantFight／pickup／door／noKey／tooHurt／stairs／talk／shop／deal／level／sage／choose／script（move、pickup 可能帶 pincer／echo／aura）
  → main.js 依事件演出（動畫、音效、提示、HUD）
    → 有 script 時 runScript：演出指令自己處理，狀態指令（give／stat／key／flag／set／swap／leave／layer／ending）呼叫 MT.applyCmd
  → autosave → MT.Sync.saveAuto(MT.pack(st)) → localStorage → 2.5 秒後 push 到 GitHub

全域命名空間只有 window.MT；data／core 在 node 下掛在 globalThis.MT，讓解題器直接重用規則與劇本的狀態效果。

8.3 版本號與 service worker 規則

  • 版本號在兩處：index.html 的 MT.VERSION（設定頁顯示「網頁版 vX」）與 sw.js 的 VERSION = 'mt-X'
  • 改版必須把 sw.js 的 VERSION 加一，否則已開過的瀏覽器會繼續用快取裡的舊檔
  • App 外殼版號由 User-Agent 的 MagicTowerApp/x.y.z 讀出，網頁更新不需重包 App
  • 改關卡或數值後依序跑 node tools/check_reach.js、node tools/audit.js、node tools/solve.js（新手／一般／真人型／高手四種自動玩家），細節見 docs/DESIGN.md
  • 改關卡、數值或道具名稱後重產通關攻略：node tools/guide.js <輸出> --width 4 --skill reflect（這組拿得到 S）
